Printing from the web that works in every browser.

A tiny library for printing PDFs, HTML elements, images, JSON tables and raw markup — now with Safari, Firefox and mobile fixed, and every documented feature verified in Chromium, Firefox and WebKit.

Try every print type

Each button runs a real print job with the options shown underneath it.

Events from the last print job show up here.
type: 'pdf'

PDF document

Downloaded first, then printed. Safari, iOS and Android open it in a tab instead, because they cannot print a PDF from a hidden frame.

type: 'image'

Images

One image or an array of them, each waited for before the dialog opens.

type: 'json'

Data as a table

Pass an array of objects and the columns you want, with per column widths and styles.

type: 'raw-html'

Raw HTML string

No element needed — hand it markup and it prints.

Install

Prebuilt files ship in dist/, so there is nothing to compile in your app.

Plain HTML

Drop in a script tag

<link rel="stylesheet" href="print.css">
<script src="print.js"></script>

<button onclick="printJS('invoice.pdf')">
  Print
</button>
Bundlers

npm, bun or yarn

bun add github:saileshkush95/Print.js

import printJS from 'print-js'
import 'print-js/dist/print.css'

printJS({
  printable: 'invoice',
  type: 'html',
  targetStyles: ['*']
})
React

usePrint hook

import { usePrint } from 'print-js/react'

const { print, targetRef, isPrinting } =
  usePrint({ type: 'html' })

<div ref={targetRef}>Invoice</div>
<button onClick={() => print()}>
  {isPrinting ? 'Preparing…' : 'Print'}
</button>
